# App Template

This is the standard application template generated via `cargo generate`.

## Quick Start

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Configure your `DATABASE_URL` in `.env`.
3. Run the application:
   ```bash
   cargo run
   ```
4. Add new modules in `src/main.rs` using `.module(...)`.
